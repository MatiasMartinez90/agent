# 🤖 Kiro Project Configuration

## 📁 Estructura de .kiro

```
.kiro/
├── README.md                    # Este archivo
├── settings/                    # Configuraciones del proyecto
│   ├── project.json            # Configuración principal
│   ├── mcp.json               # Model Context Protocol
│   ├── steering/              # Reglas de comportamiento
│   └── hooks/                 # Hooks de automatización
├── tasks/                      # Sistema de tareas (ya creado)
├── agents/                     # Agentes especializados
├── workflows/                  # Flujos de trabajo automatizados
├── templates/                  # Plantillas de código
├── docs/                       # Documentación del proyecto
├── scripts/                    # Scripts de automatización
└── monitoring/                 # Métricas y monitoreo

```

## 🎯 Funcionalidades Principales

### 1. **Settings** - Configuración del proyecto
### 2. **Agents** - Agentes especializados (como .claude)
### 3. **Workflows** - Automatización de procesos
### 4. **Templates** - Plantillas de código
### 5. **Hooks** - Automatización por eventos
### 6. **Tasks** - Sistema de tareas (ya implementado)
### 7. **Monitoring** - Métricas y análisis
### 8. **Scripts** - Automatización personalizada

---

**Cada carpeta tiene funcionalidades específicas detalladas en sus respectivos archivos.**
